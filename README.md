## Current work

**OrigenLab** (CTO, since January 2026). Commercial software for a laboratory-equipment business: the public site, an email intelligence pipeline, a FastAPI operator API behind a Cloudflare Worker, a React CRM with Google Workspace sign-in, and a Supabase V2 data platform under migration. One writer per table, every mutation an idempotent command, no autonomous sending. [Repository](https://github.com/rafaelRojasVi/origenlab).

**BENKER** (CTO, since August 2026). A commercial database and process-tracking platform for a heavy-civil-works contractor: organisations, studies, quotations, approvals, and outcomes on one identity layer, plus a marketing subsystem with eligibility and consent rules. Next.js, TypeScript, PostgreSQL. Private.

**Campo Digital** (contract, since August 2026). Geospatial and forestry platform: LiDAR timber-volume measurement, forestry GIS for properties and stands, and a company portal. Python, TypeScript, PostGIS. [Repository](https://github.com/rafaelRojasVi/campo-digital-platform).

**Heavy Ops** (since August 2026). A platform matching construction companies with eligible, credentialed machine operators. Eligibility is evaluated before ranking and persisted with reasons; the platform records confirmation without moving money. FastAPI, SQLAlchemy, PostGIS, React. Private.
